# Charcoal web controls

The browser controls use explicit background21, raised2F, interactive38, border45, textF4, secondary/focusB4 and selection59 roles. The initial page is charcoal independent of system mode. Existing fields, actions, JavaScript, Rust mathematics, CLI and scientific raster bytes are unchanged. Canvas CSS only constrains display width for smaller viewports; its intrinsic dimensions and image data remain owned by the original renderer.

The scientific black/white limit-set canvas deliberately retains its intended colors. It is exempt from an application-background area detector. No inversion, filters or recolored mathematical fields are introduced. The existing terminal CLI inherits its terminal configuration.

Actual checked Ithon/Chromium acceptance and the established Cargo/wasm-bindgen build are defined in the new workflow. Compiler/dependency resolution and exact canvas comparison against the preceding page are retained. Current results are pending. This project has no Android application; no release, deployment or user installation is changed.
